📖 О проекте
GeoTracker: Картограф — это десктопное приложение, созданное специально для картографов, работающих с панорамами в Яндекс.Картах и аналогичных сервисах. Оно превращает рутинный процесс расстановки точек в увлекательную игру с элементами геймификации, подробной статистикой и финансовым учётом.

Приложение помогает отслеживать продуктивность, работать по спринтам, анализировать свои результаты и видеть реальный заработок в реальном времени.

📦 Требования
Системные требования
Операционная система: Windows 10/11 (возможна работа на Linux/macOS с доработками)

Python: версия 3.11 или выше

Оперативная память: от 4 ГБ (рекомендуется 8 ГБ)

Свободное место на диске: от 100 МБ

Зависимости
Все зависимости указаны в файле requirements.txt:

txt
PyQt5>=5.15.0
keyboard>=0.13.5
matplotlib>=3.5.0
🛠️ Установка и запуск
1. Клонирование репозитория
bash
git clone https://github.com/your-username/geotracker-cartographer.git
cd geotracker-cartographer
2. Установка зависимостей
bash
pip install -r requirements.txt
Или вручную:

bash
pip install PyQt5 keyboard matplotlib
3. Запуск приложения
bash
python main.py
4. Настройка перед использованием
Откройте вкладку с панорамами в браузере

Нажмите "Старт" в главном окне

Добавляйте точки с помощью глобального хоткея Ctrl+A

Настройте длительность спринтов и цену точки в окне "Настройки" (⚙️)

🧠 Как это работает
Сессия — период работы от нажатия «Старт» до «Стоп»

Спринт — часть сессии, ограниченная по времени

Точка — единица работы (добавляется хоткеем Ctrl+A)

Продуктивное время — время, проведённое во вкладке «Бэкофис Панорамы» во время спринта

Скорость — количество точек в час продуктивного времени

Заработок — произведение количества точек на цену точки

🐛 Известные проблемы и их решение
Проблема	Решение
Скорость показывает прочерк	Убедитесь, что вы работаете во вкладке с панорамами. Добавьте свой маркер в config.py
Глобальный хоткей не работает	Запустите приложение от имени администратора
Ошибка при сохранении	Проверьте права на запись в папке с приложением
